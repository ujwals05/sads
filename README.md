# SADS

**Security-Aware Dependency Selection (SADS)** is an AI-powered coding assistant designed to make software development safer by evaluating dependencies before they are selected and installed in a project.

AI coding assistants can recommend or install packages that may contain known vulnerabilities, have poor maintenance, introduce risky transitive dependencies, or be unsuitable for the intended functionality. They may also suggest packages that do not exist, creating potential software supply-chain risks.
